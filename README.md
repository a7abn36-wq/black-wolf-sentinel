# 🐺 Black Wolf Sentinel — Runner Shell

الريبو ده **قشرة تشغيل بس** — مش فيه الكود.

- كود السنتينل الحقيقي عايش في ريبو خاص: `a7abn36-wq/black-wolf` (مجلد `sentinel/`)
  وبيتسحب وقت التشغيل عبر توكن مشفّر في Actions Secrets (`REPO_PAT`).
- الـ workflow بيقلّب السنتينل 24/7 على ورديات ~5.5 ساعة: كل وردية بتشيل اللي بعدها
  تلقائياً (workflow_dispatch chain) + كرون كل 30 دقيقة شبكة أمان.
- **`status.json`** في جذر الريبو ده = آخر نبضة حية من السيرفر — أداة OFM بتقرأه
  مباشرة في تاب «🛡 الحراسة» (raw link، CORS مفتوح، حدّث كل ربع دقيقة تقريباً).

## الـ Secrets المطلوبة (Settings → Secrets → Actions)

| الاسم | معاه إيه |
|---|---|
| `REPO_PAT` | Personal Access Token عنده صلاحية `repo` يقرا الريبو الخاص |
| `BOT_TOKEN` | توكن بوت تليجرام من BotFather |
| `CHAT_ID` | آي دي الشات الشخصي |

## ليه ريبو عام؟

GitHub Actions بيدى دقائق مجانية **غير محدودة** للريبوهات العامة — ده اللي يخلي
الرصد 24/7 ببلاش تماماً. الكود السري بيفضل خاص لأنه في الريبو التاني.
